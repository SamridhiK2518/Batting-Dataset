# Virat Kohli Batting Analysis 🏏

This project explores and visualizes Virat Kohli's batting performance using a
batting dataset. The analysis uses Python, Pandas, Seaborn, and Matplotlib to
identify patterns and trends in his performance.

## Analysis Includes

- Runs scored across innings
- 1st innings vs 2nd innings comparison
- Pre- and post-transformation performance
- Balls faced before and after transformation
- Runs scored by batting position
- Dismissal patterns
- Yearly batting trends
- Performance against different oppositions
- Batting position across different years and oppositions
- Data visualization using boxplots, bar plots, point plots, and FacetGrid

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Kaggle

## Dataset

The project uses a Virat Kohli batting dataset containing match-level batting
information used for exploratory data analysis and visualization.
